# Middleware Stack (Docker Compose)

One-command setup for a common middleware stack on Linux / WSL. Brings up 13 services across databases, cache, web, messaging, search, HA and monitoring, with MinIO as an optional add-on.

## Quick Start

```bash
git clone https://github.com/alaku0721/docker-middleware-all.git
cd docker-middleware-all
bash setup.sh
```

`setup.sh` automatically: detects/installs Docker if missing, configures registry mirrors for China, pulls all images (with automatic mirror fallback), and starts every service via `docker compose up -d`.

## Services

| Service      | Category        | Port(s)          | Access / Verify                              |
|--------------|-----------------|------------------|----------------------------------------------|
| Nginx        | Web / proxy     | 8080             | http://localhost:8080                        |
| Tomcat       | Java app        | 8081             | http://localhost:8081/myapp/                 |
| MySQL        | RDBMS           | 3306             | `docker exec -it mysql mysql -uroot -proot123456` |
| PostgreSQL   | RDBMS           | 5432             | `docker exec -it postgres psql -U postgres`  |
| MongoDB      | Document DB     | 27017            | `docker exec -it mongodb mongosh -u root -p mongo123` |
| Redis        | Cache           | 6379             | `docker exec -it redis redis-cli -a redis123` |
| ZooKeeper    | Coordination    | 2181             | `docker exec -it zookeeper zkServer.sh status` |
| Kafka        | Messaging       | 9092             | see below                                    |
| RabbitMQ     | Messaging       | 5672, 15672      | http://localhost:15672 (admin / rabbit123)   |
| Elasticsearch| Search          | 9200             | `curl http://localhost:9200`                 |
| Keepalived   | High availability | -             | `docker exec -it keepalived ip addr`         |
| Prometheus   | Monitoring      | 9090             | http://localhost:9090                        |
| Grafana      | Dashboards      | 3000             | http://localhost:3000 (admin / admin123)     |

Optional service (not started by default):

| Service | Category       | Port(s)     | Access / Verify |
|---------|----------------|-------------|-----------------|
| MinIO   | Object storage | 9000, 9001  | enable via `docker compose --profile extra up -d minio`, then http://localhost:9001 (minioadmin / minioadmin123) |

Ports are chosen to avoid common conflicts (Nginx 8080 instead of 80, Tomcat 8081 instead of 8080, RabbitMQ UI 15672, MinIO console 9001).

## Kafka quick test

```bash
docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 \
  --create --topic test --partitions 3 --replication-factor 1

docker exec -it kafka /opt/kafka/bin/kafka-console-producer.sh --bootstrap-server localhost:9092 --topic test

docker exec -it kafka /opt/kafka/bin/kafka-console-consumer.sh --bootstrap-server localhost:9092 --topic test --from-beginning
```

## Commands

```bash
bash setup.sh check     # environment check only
bash setup.sh backup    # MySQL dump + Redis persistence check
bash setup.sh down      # stop and remove containers (volumes kept)
docker compose ps       # list service status
docker compose logs -f <service>   # tail a service log
```

## Directory layout

```
├── nginx/html/, nginx/conf/ # static page + reverse-proxy sample
├── tomcat/webapps/          # deployed app
├── keepalived/keepalived.conf
├── prometheus/prometheus.yml
└── backups/                 # generated by setup.sh backup
```

## Notes

- Kafka uses the official `apache/kafka:3.7.0` image in KRaft mode (no ZooKeeper dependency). ZooKeeper is still included as a standalone service.
- MinIO is optional because its image is not reliably mirrored by public registry mirrors. Enable it with `docker compose --profile extra up -d minio` when the image can be pulled.
- Keepalived VIP failover may not work inside WSL2 due to kernel networking limits; verify on a real Linux host or VM.
